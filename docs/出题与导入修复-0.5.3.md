## 听力不会随建卷自动合成

生成题目、标准答案、图表和独立文字校审先完成。可以在待核对草稿展开“听力文字与角色”查看脚本。只有点击“单独合成听力（N 段，会消耗 TTS）”才发送 TTS 请求；也可以上传与当前题目对应的已有录音。旧任务不拥有自动合成授权。已有成功片段继续保留，下载失败会复用保存的合成结果。

## 旧失败任务怎么继续

- 题数、分值或格式失败：先继续，程序会无损整理可修复的字段和完全重复题组。仍未通过时可用“重新整理当前部分（仅文字，会调用出题服务）”；旧响应归档，成功的其他部分保留。
- 独立校审失败：会自动对定位到的部分修复一次并复查。仍有问题时，草稿保留，可明确选择“AI 修复并复查（仅文字）”。不会为失败的文字稿合成听力。
- 网络请求结果不确定：停止并保留请求记录，不在普通继续时反复发送同一请求。文字校审草稿保留，可选择明确的重新请求操作。
- 剑雅整本或多 Test 资料：点击“在资料库继续（复用已解析内容）”。复用原件、MinerU 版面与原图，不重新 OCR。新增资料默认从真题资料库入口处理。

## 答案与整本资料

资料库按 Test、科目、部分管理题组，答案和解析可单独补充。OCR 没有识别出答案键时，不能用听力稿推测的答案替代真实答案键；需要核对原页或加入答案文件。旧失败模型草稿不会被当成原始答案来源。剑雅早期册的题号可能与现行格式不同，原始编号保留，不能为了凑数静默删题。

生成题采用明确的题组计分计划；选两项/三项题组只占一个题目对象，覆盖对应的多个编号。证据通过段落或发言 ID 从实际源文提取，避免模型重抄引文时产生差异；具体答案仍需通过结构检查与独立内容校审。

听力没有官方固定脚本最低字数；旧版统一 450 词门槛已移除。参考：[IELTS Listening 题型与结构](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-listening)、[Academic Reading 结构](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)。
