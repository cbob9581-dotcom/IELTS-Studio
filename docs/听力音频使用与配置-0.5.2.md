# 听力音频使用与配置（0.5.2）

## 三个入口

打开主页的“真题资料库”，创建或选择一个资料项目，进入“听力音频”。

|入口|适用素材|步骤|
|---|---|---|
|真题脚本合成|包含 Audioscripts 的真题书|解析书籍 → 核对 Test/Part 分组 → 点击对应听力原文 → 核对原文、角色和停顿 → 试听 → 生成完整 Part|
|用户文本合成|粘贴文本、UTF-8 TXT/MD|填写 Test/Part → 创建听力稿 → 编辑角色和停顿 → 试听 → 生成完整 Part|
|上传音频|一个或多个 MP3、PCM WAV、Vorbis OGG|选文件 → 检查可播放性 → 试听 → 填写 Test/范围/顺序 → 启用 → 保存绑定|

上传音频不会调用出题模型或 TTS，也不需要配置云服务。单文件上限100MB；更大的 WAV 可转换为 MP3，或按 Part 拆分。PDF 仍为单文件200MB上限，按页数和体积自动分批，复用已完成解析。

## TTS配置

在“设置”的云服务配置中启用 Qwen TTS，密钥保存在 Windows 凭证管理器。

|配置|本次验证使用值|
|---|---|
|服务地址|`https://dashscope.aliyuncs.com/api/v1`（中国内地服务，与密钥区域保持一致）|
|模型|`qwen3-tts-flash`|
|朗读语言|English，当前听力合成适配器固定英文|
|角色音色|示例：PETER → `Aiden`；JAN → `Cherry`；NARRATOR → `Ryan`|
|请求超时|沿用设置中的值，本次测试为120秒|
|生成并发数|听力稿内可选1–3，默认3；云请求不稳定时可选1，保存后继续|

主配置中的 `Aiden|Cherry|Ryan` 可用于预填角色音色；听力稿界面中，每个角色应填写单个音色名。单人独白只需一个角色和音色。更换模型时，请先确认该模型支持所填音色。

当前接口单次正文上限600字符，导入长稿时按句和空格拆到550字符以内；编辑后超过600字符会提示修正。接口参数以[阿里云 Qwen TTS API](https://www.alibabacloud.com/help/en/model-studio/qwen-tts-api)为准。当前界面没有伪装成生效的独立语速滑杆。

## 用户文本与节奏

推荐每个角色另起一行，例如：

```text
JAN: Hello. I'd like some information about the conservation group.
PETER: Of course. We have several regular activities.
```

未标记角色的正文按独白处理。自动识别的角色和清理结果须在朗读稿中核对；原稿始终保留。普通句子中的数字及冒号不会作为题号直接删除。

时间线区分“正文”与“停顿”。换人停顿初值0.3秒，同角色新段初值0.6秒；这是可编辑的试听起点，不代表官方固定秒数。可插入读题、检查答案等长停顿，单次0–120秒。句内节奏由标点和模型处理，不逐词插入空白，也不通过拉伸语音凑时长。

先生成前3段试听，检查角色音色、长句与换人节奏，再生成完整 Part。试听和完整生成共用分段缓存。最后按时间线组装为每 Part 一个24kHz单声道PCM WAV，播放器不逐句换文件。

## 原版音频与绑定

本次提供的目录包含16个剑17原版MP3，已逐个检查解码、时长和哈希。文件名对应关系为：

`ELT_IELTS17_t1_audio1.mp3` → Test 1 / Part 1；`t4_audio4` → Test 4 / Part 4。

每个 Test 可按100、200、300、400的顺序绑定四个Part。同一Part有多个文件时，给出各自的播放序号。原始录音已有的语音和停顿保持原样，不追加合成停顿。

新发布的单项/Part练习按所选音轨实测时长计时；从整套材料中选择已标记的Part时，按对应起止区间计时。旧卷保持原版本，需重新发布新版本才能应用新计时。完整机考的读题和末尾检查安排仍需结合录音核对，不能由纯脚本自动推断。

整套一个文件时选择“整套听力”，不会重复播放四次。需要分项训练时，展开起止时间编辑，标记各Part的时间范围；未标记时不能准确跳转，界面会提示选择完整听力或先补标记。

同一个Part请启用一种素材版本。合成与原版录音同时覆盖同一Part会阻止发布并说明冲突。合成结果默认未启用，试听片段不能用于发布；核对完整音轨后再启用。发布只引用实际选择题组所需的Part。

## 失败和恢复

- 进度显示实际阶段、完成段数和总段数；一次失败不会清除其他已完成片段。
- “继续未完成片段”复用已完成的有效缓存。关闭应用后，从已保存听力稿继续。
- 修改一段正文或音色，只会让对应缓存失效；修改停顿只需重新组装音轨。
- 收费生成POST与音频下载GET分开。下载失败优先恢复原地址，不会因为下载重试重新提交生成；临时地址受Windows凭证管理器保护，不进入普通项目JSON。
- 下载的暂时性错误最多重试3次，遵守数字形式的Retry-After；等待超过60秒时交给用户稍后继续。
- 生成POST失败或超时不会自动无限重发。提交超时可能无法确认云端处理与计费结果，手动重试可能产生新费用。
- 下载地址失效时可点“重新请求失败片段（可能计费）”；已有可用片段保留。
- 密钥、余额、模型权限错误需到设置修正；不会用空音轨或部分成功的音轨假装完整生成。

## 保存、考试与验证范围

设置中的“资产库”和“学习记录”目录仍可由用户选择。听力原稿、缓存和音轨位于资产库的 `source-library` 项目内；发布卷包保留独立版本。更新素材不会修改已经发布或正在使用的旧卷版本。

素材显示“真题脚本合成”“用户文本合成”或“上传音频”。考试视图隐藏听力稿，训练模式可展开查看。原版与合成语音的口音、语气、读题时长不保证相同，长停顿需按题组核对。

机考末尾检查时间与纸笔考试誊写时间不同，参考[IDP机考说明](https://ielts.idp.com/nigeria/about/ielts-on-computer)。不能根据书后脚本推断原版录音的精确停顿，也不能把较短合成稿直接当作已经复刻原版完整计时。

实际验证结果另见 `listening-audio-verification.md`。16组脚本结构通过不代表16组都已实际付费合成；各次真实合成与失败恢复覆盖范围按报告记录。
