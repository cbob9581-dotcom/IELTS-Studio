# 0.6.1 使用流程修复

## 启动和数据

构建脚本会更新项目根目录、Windows 桌面和开始菜单中的 IELTS Studio 快捷方式，统一指向 `dist/0.6.1/ielts-desktop.exe`。已有快捷方式分别备份在本机 `.tools/shortcut-backups` 中。旧发行目录仍保留，直接运行旧目录内的程序仍会启动旧版。

此更新不迁移资产库、学习记录或凭证。用户已有的资产库 `F:\IELTS1\A`、学习记录 `F:\IELTS1\B` 保持原设置。安装包与本地测试资料不进入源码仓库。

## 考生使用流程

- 阅读按三篇文章切换，只显示当前文章对应的题目；完整卷仍是全卷 40 题。全卷题号导航会切换到题目所属文章。切换保留答案和计时，练习解析在切换文章时关闭。
- 生成卷在结构检查和独立校审通过后自动入库；考生不需要逐题核对答案、勾选确认或点击发布。答案编辑保留在默认收起的可选管理区。
- 听力文字通过检查后，仍需用户选择音频来源。可以上传完整录音，系统先验证音频可解码，再绑定入库；也可以明确选择合成语音。文字失败不会触发 TTS。
- 题册导入按 Test 整理，缓存和完成的部分继续保留。选择已整理的 Test 后点击“使用这套试卷”即可入库，无须勾选已人工核对答案。缺少答案、必要图片或听力音频、有未解决冲突时仍不能作为完整卷使用。

## 已知边界和验证

本次修复使用离线回归、真实已保存阅读卷和已解析的剑雅资料进行验证，不发送付费出题、OCR、ASR、评测或 TTS 请求。真实阅读卷界面验证了 13/13/14 题分组、跨篇答案保留与计时保留。在强制禁云的原生桌面验证中，已通过校审的生成阅读卷自动入库；已解析的剑雅 17 Test 1 阅读卷在没有人工核对确认字段时成功入库，三篇、40 题及答案完整。此范围不等于重新验证了所有四科的在线生成和整本 PDF 的首次云解析。

旧任务里不真实的答案引文仍然不能通过校验。系统不会将模型编造的引文当成来源，也不会将失败草稿强制发布。旧任务原件、响应和已成功的步骤保留；继续修复文字可能产生文本服务费用，应按任务预算执行。旧版原始响应的校验失败不能仅靠升级自动变成合格试卷。

云服务地址、模型、请求预算与密钥配置继续使用 [0.6.0 配置说明](系统优化与配置-0.6.0.md)。本次没有自动修改这些设置或授权新的付费请求。
