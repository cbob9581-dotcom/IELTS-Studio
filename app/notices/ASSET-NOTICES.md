# Scene asset provenance

The examiner was authored with MPFB/MakeHuman source assets declared CC0 in the original source packs. The female suit was supplied as Fem_Suit2, author MRT, license CC0. Original source manifests, hashes and license headers remain in .tools/character-sources and .tools/mpfb-user.

The current blonde hair is original procedural geometry from tools/blender/rebuild_hair_cards.py and its refinement scripts. It does not contain the older Daisy hair mesh or textures. The historical Daisy attribution is retained with archived authoring revisions in assets/characters/examiner/HAIR-CREDITS.md.

The room, paper/card artwork, preview audio tones, chart and application icon are original project assets.

Source records: assets/characters/examiner/route-review.md, .tools/character-sources/sources.json, rooms/speaking/runtime/manifest.json.
